# 深坑街頭霸王：貓狗鼠大作戰

依《深坑街頭霸王_完整規則書_v0.2》製作的純 HTML / CSS / JavaScript 遊戲，使用原型提供的卡牌美術。可以直接以瀏覽器開啟，也可以部署到 GitHub Pages。

## 開始遊玩

開啟 `index.html`，選模式、人數與是否啟用角色能力，再按「洗牌，開始對決」。

- **單人對電腦**：你固定是玩家 1，身分及角色隨機；另外 3–4 位玩家由電腦操作。
- **同一裝置輪流**：4 或 5 位真人共用裝置；出牌、閃避、自救交接時以遮罩隱藏手牌。
- 點手牌使用。攻擊、偷牌與狂吠需要再點選亮框玩家。點玩家可查看公開能力與裝備。
- 結束回合後，自選多餘手牌棄到當前生命上限。
- 完整出牌結算後及回合邊界會自動儲存；首頁按「繼續上次對局」恢復。
- 切換瀏覽器、網址、裝置或清除瀏覽資料，不會共用存檔。瀏覽器拒絕本機儲存時會顯示提示。

## 上傳 GitHub Pages

1. 解壓縮本檔案包。
2. 在 GitHub 建立 repository，例如 `shenkeng-street-kings`。GitHub Free 可使用公開儲存庫啟用 Pages。
3. 在儲存庫選 **Add file → Upload files**，將解壓後的檔案及 `assets` 資料夾上傳並提交。**要讓 `index.html` 位於儲存庫最外層，不要只上傳 ZIP，也不要多包一層資料夾。**
4. 開啟 **Settings → Pages**。
5. 在 **Build and deployment → Source** 選 **Deploy from a branch**。
6. Branch 選 **main**（或實際存放檔案的分支），資料夾選 **/(root)**，按 **Save**。
7. 等待部署完成，開啟 Pages 顯示的網站網址。

專案網站網址通常為 `https://你的帳號.github.io/shenkeng-street-kings/`。

設定依據：[GitHub 官方 Pages 發布來源說明](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)。

若只顯示 README，請檢查 `index.html` 是否在選定的發布目錄；若圖片未出現，檢查 `assets` 資料夾及英文檔名是否完整、大小寫是否一致。

## 檔案結構

```text
index.html          入口與頁面結構
style.css           桌面與手機版樣式
engine.js           獨立規則引擎
app.js              互動介面、電腦策略與本機存檔
assets/             四張原始美術圖，以 CSS 定位顯示各卡面
rules-v0.2.pdf      原始完整規則書
tests/engine.cjs     可重跑的規則測試
.nojekyll           純靜態網站標記
README.md           本說明
```

不需 npm、建置流程、伺服器、API 金鑰或 CDN。所有資源使用相對路徑，支援 GitHub 專案網站子目錄。`tests` 不影響遊戲執行。

## 已實作規則

- 4 人：巡守犬、野貓 2、黑鼠；5 人加入忠犬。
- 七種角色、14 種手牌共 24 張，身分與角色獨立分配。
- 存活座位距離、角色與裝備加成、攻擊次數、同槽裝備替換。
- 飛簷貓首次出爪雙閃、暗道紅框判定、混戰順時針逐人處理。
- 背心先擋致死傷害、老獵犬瀕死觸發、本人臭豆腐自救。
- 擊殺野貓抽 3、巡守犬誤殺忠犬棄掉全部手牌與裝備。
- 黑鼠最後單挑優先判勝；忠犬須存活、野貓可出局後共享勝利。
- 牌庫空時重洗；正在結算的牌不進重洗；夜行貓未選牌置底。
- 花子精摸牌選對手後隨機偷其裝備；神偷與狂吠可選手牌區或指定公開裝備。

## 數位版範圍與約定

- **沒有跨裝置網路連線**；GitHub Pages 提供靜態網站，這個版本的對局在各自瀏覽器執行。
- 電腦使用自己的身分、公開巡守犬、生命與裝備、公開出爪紀錄做簡易策略，不根據對手隱藏身分或手牌挑目標。策略不等於真人談判，也不是平衡性驗證。
- 電腦預設會閃避、自救及使用暗道；真人可自行放棄。電腦為避免單回合長時間循環，最多連續出牌 40 次後結束回合；真人沒有此限制。
- 同機的交接遮罩是防止誤看，不是防作弊系統；狀態與存檔都在本機，開發者工具可讀取。請讓其他玩家移開視線。
- 自動存檔不包含尚未完成的選擇。結算途中關閉頁面，會回到最近一次完整存檔。
- 牌庫枯竭不判負。若原型出現沒有合法進展的僵局，依規則由玩家同意結束，回首頁重開；不另指定勝者。
- 遊戲內仍可閱讀原始 PDF；卡面是摘要，衝突時以完整規則 v0.2 為準。

## 驗證

如果電腦已安裝 Node.js，在此資料夾執行：

```sh
node tests/engine.cjs
```

測試涵蓋牌數與唯一 ID 守恆、4/5 人配置、距離、武器更換、背心、瀕死、黑鼠勝利順序、事件中途勝利、摸牌不足與裝備偷取，以及 60 局固定種子的模擬。部分隨機模擬會達到 300 回合測試上限；此上限僅用於測試，不會強制宣判遊戲輸贏。

另外已在 Edge 瀏覽器檢查開局、角色選牌、棄牌、圖鑑、交接遮罩、重整續玩及 390px 手機版無頁面橫向溢出。電腦策略屬試玩等級。
